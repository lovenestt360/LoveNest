# LoveNest — exploração de sistema visual v1

Protótipo **isolado** com três direções (A · Quieto, B · Diário, C · Presença) para comparação. Nenhuma direção está escolhida.

- Abrir `index.html` diretamente no browser. Não depende de build, nem de Supabase.
- Nenhum ficheiro de `src/` importa este protótipo; o build da app (Vite) não o inclui.
- Fotografias são marcações provisórias com shot brief. Nenhuma imagem com licença por confirmar.
- Conteúdo de exemplo: Ana (quem usa a app, rosa) e Miguel (par, azul). Rosa e azul nunca representam género.
- Base: brief de design rev. 3 (9 out 2026) e auditoria Fases 0–4 rev. 2.

Não integrar no produto antes da escolha do dono.
