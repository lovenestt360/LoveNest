LoveNest — Política de Privacidade

Política de Privacidade

Última atualização: 30 de julho de 2026

O LoveNest é uma aplicação para casais. Alguns dados partilhados entre parceiros fazem parte do funcionamento da app. Esta política explica exatamente o quê, porquê e como.

1. Quem somos

O LoveNest é desenvolvido e operado a título pessoal por Dilson Quissico, acessível em lovenestt.com. Para contacto direto, usa o endereço indicado na secção 9.

2. Dados que recolhemos

Recolhemos apenas os dados necessários para o funcionamento da aplicação:

  • Conta: endereço de email e palavra-passe (geridos pela Supabase Auth)
  • Perfil: nome, género, fuso horário e nível de nível de guardião
  • Espaço de casal: iniciais do casal, identificador do espaço partilhado
  • Ciclo menstrual: perfil de ciclo, registos de período, sintomas diários e registos de intimidade — apenas para a utilizadora que os introduz (ou visíveis ao parceiro, se configurado)
  • Desafios e jornada: desafios concluídos, entradas do diário de casal
  • Atividade diária: registo de dias consecutivos de uso (streak)
  • Notificações push: token do dispositivo para envio de notificações
  • Localização (opcional): coordenadas GPS, apenas quando o utilizador ativa explicitamente a partilha de localização

3. Como usamos os dados

Os dados são usados exclusivamente para:

  • Fornecer as funcionalidades da aplicação (ciclo, desafios, jornada, streak)
  • Sincronizar informação em tempo real entre os dois parceiros do mesmo casal
  • Enviar notificações push relevantes (ex: desafio concluído pelo parceiro)
  • Lembretes inteligentes de uso da app (máximo 3 por dia)

Não usamos os dados para publicidade, não os vendemos, e não construímos perfis para fins comerciais.

4. Partilha de dados entre parceiros

Dentro de um casal, alguns dados são partilhados por design:

  • O estado do ciclo menstrual é visível ao parceiro, de acordo com o nível de partilha configurado pela utilizadora
  • Os desafios concluídos são visíveis a ambos
  • A localização só é visível ao parceiro quando ambos ativam explicitamente a partilha
  • Entradas do diário marcadas como privadas não são partilhadas

5. Terceiros e subprocessadores

  • Supabase (supabase.com) — base de dados, autenticação e armazenamento. Servidores na AWS us-east-1.
  • Vercel (vercel.com) — alojamento da aplicação web.
  • Google Firebase Cloud Messaging — envio de notificações push para Android e iOS.
  • Google Play Store — distribuição da app Android.

Estes fornecedores têm as suas próprias políticas de privacidade. Não partilhamos dados com outros terceiros.

6. Segurança

Todos os dados são transmitidos via HTTPS. O acesso à base de dados é protegido por Row-Level Security (RLS) — cada utilizador só acede aos seus próprios dados e aos do seu espaço de casal. As palavras-passe são geridas pela Supabase Auth e nunca armazenadas em texto simples.

7. Retenção de dados

Os dados são mantidos enquanto a conta estiver ativa. Ao eliminar a conta, todos os dados associados são permanentemente removidos da base de dados dentro de 30 dias. Os dados de ciclo menstrual podem ser exportados antes da eliminação contactando o suporte.

8. Os teus direitos

Tens direito a:

  • Acesso: solicitar uma cópia dos teus dados
  • Correção: corrigir dados incorretos diretamente na app
  • Eliminação: eliminar a conta e todos os dados associados
  • Portabilidade: solicitar exportação dos dados em formato legível
  • Oposição: desativar notificações push a qualquer momento nas definições da app

Para exercer qualquer um destes direitos, contacta-nos através do email abaixo.

10. Alterações a esta política

Caso alteremos esta política de forma significativa, notificamos os utilizadores por push notification ou por email, com pelo menos 7 dias de antecedência. A data de "última atualização" no topo reflete sempre a versão em vigor.
